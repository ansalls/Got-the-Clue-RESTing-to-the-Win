# Agent Guidelines

## Project expectations
- Maintain **full automated test coverage** for new and existing functionality.
- All tests must **pass locally** before delivery.
- Keep a **strong security posture** (validate inputs, least-privilege access, avoid secrets in code, and follow OWASP best practices).
- Write comments that explain **"why"** something is done, not **"what"** the code is doing.
- Deliver **beautiful, polished UI implementations** for all relevant features (consistent spacing, typography, and accessibility).
